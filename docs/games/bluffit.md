# ブラフィット（BLUFFIT）

2〜6人の基本ゲーム。日本語版の[公式紹介・カード写真](https://sugorokuya.jp/p/bluffit)、[一騎打ちの解説](https://sugorokuya.jp/stories/46/1)、[詳細な手順](https://bodoge.hoobby.net/games/bluffit/instructions/54833)を参照。まとめ取りと特殊カードは対象外。

全員が1〜10を各1枚持つ。別セットから無作為に人数分の場札を出し、先手を抽選する。全員が指し値を伏せたら先手から順番に1回ずつ、場札の確保か他人の確保札への一騎打ちを行う。同値は挑戦側の勝ち。敗者は取り直せず、勝者への再挑戦は可能。残った場札は捨てる。確保した札を得点の山に積み、今回の最高の確保札を取った人が次の先手。同値なら先に手番が来た人を優先する。

指し値を混ぜて次の場札にする。通常10回の後、得点札が2枚以上の人だけが、そのうち1枚を消費して最終戦を行う。残った得点札の合計を比較し、最多得点者は全員勝利。

同時選択中の手番IDは空。選択済みかどうか・場札・確保札・得点の山の一番上は公開し、手札と指し値は本人だけに配信する。一騎打ちの数値は当事者だけが対戦履歴から確認できる。最終戦で消費した札を推測できないよう、得点山の表示は精算まで維持する。結果では全員の合計点を公開。再接続は同じ視界を復元し、再戦は初期状態から始める。時間制限はなく、退出は共通ルーム仕様に従う。

## 受け入れ確認

一騎打ちでは、当事者は自分の指し値を見ながら相手の札をめくって勝敗を確認する。他のプレイヤーには両方の札を伏せたまま、争った得点と勝者だけを示す。演出は各端末でスキップでき、他の参加者の確認を待たずに次の操作に進める。

- [ルールテスト](../../packages/shared/src/games/bluffit/__tests__/logic.test.ts)では、同値での奪取、奪取後の再挑戦、残った場札の破棄、次の先手、最終戦と同点優勝を確認する。
- [定義テスト](../../packages/shared/src/games/bluffit/__tests__/definition.test.ts)では、不正入力と二重送信の拒否、保存状態から復元した本人・相手の視界を確認する。
- [2画面での対戦テスト](../../e2e/tests/game-bluffit.spec.ts)では、PCとモバイルのロビーから対戦を開始し、指し値を伏せた後の再接続、一騎打ち、全11ラウンドの精算、再戦を確認する。
